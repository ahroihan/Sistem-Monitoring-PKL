# Sistem-Monitoring-PKL


## Sistem Monitoring PKL SMK
## Dari Absensi GPS sampai Sidang Ujian Akhir — Semua di Satu Platform

Sekolah Anda masih mengelola PKL dengan:

❌ Absensi manual (siswa bisa nitip absen)

❌ Jurnal kertas (hilang, sobek, basah)

❌ Nilai di-rekap manual (rawan salah hitung)

❌ Ujian akhir tidak terjadwal (penguji bentrok)

❌ Laporan dibuat berhari-hari (tanda tangan susah)

**Sudah waktunya digitalisasi.** 🚀

---

## 🎯 Fitur Unggulan

### 📍 Absensi GPS Anti-Manipulasi
Siswa hanya bisa check-in/out di radius lokasi PKL. Sistem catat GPS, foto selfie, dan waktu secara otomatis.

### 📓 Jurnal Harian Digital
Siswa isi jurnal dari HP. Guru validasi + beri nilai harian real-time. Tidak ada lagi jurnal hilang.

### 📊 Nilai Terintegrasi Otomatis
Nilai PKL (40%) + Jurnal (30%) + Ujian Akhir (30%) dihitung otomatis. Predikat A/B+/B/C/D tanpa hitung manual.

### 🎓 Sidang Ujian Akhir Terstruktur
Admin jadwalkan ujian dengan multi-penguji. Penguji nilai dari platform, sistem rata-rata nilai otomatis.

### 📄 5 Laporan Siap Cetak PDF
- Daftar Peserta PKL
- Kehadiran
- Nilai dari Tempat PKL
- Kunjungan Pembimbing
- Laporan Akhir

Semua dengan header sekolah + tanda tangan Kepala Sekolah.

### 🔐 Multi-Role & Aman
Admin, guru pembimbing, guru penguji, siswa — masing-masing punya hak akses terpisah. Password terenkripsi Argon2id.

### 💾 Backup Otomatis
Database backup setiap hari. Bisa download SQL kapan saja. Restore dengan 1 klik.
